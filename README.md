# 🩺 Plantões

Controle financeiro de plantões médicos.

## Deploy no Vercel (recomendado)

### Opção A — Interface web (mais fácil)
1. Crie conta em [vercel.com](https://vercel.com) com sua conta Google
2. Suba o projeto no GitHub (veja abaixo)
3. No Vercel: "Add New Project" → seleciona o repositório → Deploy

### Opção B — Terminal
```bash
npm install
npx vercel
```

## Subir no GitHub
```bash
git init
git add .
git commit -m "primeiro commit"
# Crie um repositório no github.com, depois:
git remote add origin https://github.com/SEU_USUARIO/plantoes-app.git
git push -u origin main
```

## Rodar localmente
```bash
npm install
npm run dev
```

## Instalar no iPhone como app
1. Abra a URL do Vercel no **Safari**
2. Toque no ícone de compartilhar (quadrado com seta pra cima)
3. "Adicionar à Tela de Início"
4. Pronto — vira ícone igual a um app nativo! 🎉
